# decimal-labs/.github

Organization-wide community health files for [decimal-labs](https://github.com/decimal-labs).

GitHub falls back to this repository for any community health file a repository does not define
itself, so everything here is a **default**: it applies to a repository until that repository ships
its own version, and a repository-level file always wins.

| Path | What it does |
|---|---|
| `profile/README.md` | The landing page at [github.com/decimal-labs](https://github.com/decimal-labs) |
| `SECURITY.md` | The **Security** tab and the "report a vulnerability" path on every repository |
| `CODE_OF_CONDUCT.md` | Contributor Covenant 2.1, linked from every repository's community profile |
| `CONTRIBUTING.md` | Shown when someone opens an issue or a pull request |
| `.github/ISSUE_TEMPLATE/` | Default issue forms and the template chooser |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default pull request template |

Corrections are welcome — these files are the first thing a new contributor reads, so a confusing
sentence here is worth an issue. Anything security-related belongs in
[SECURITY.md](./SECURITY.md), never in a public issue.
